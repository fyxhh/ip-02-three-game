# 滚动天空 · 蓝色小球 3D 网页小游戏

用 **Three.js** 制作的 3D 网页小游戏，玩法参考《滚动天空》（Rolling Sky）。

## 🎮 在线试玩

**https://fyxhh.github.io/ip-02-three-game/**

用手机或电脑浏览器打开上面的链接即可直接游玩（无需安装）。

## 🕹️ 玩法说明

- 控制蓝色小球在滚动天空的道路上前进（方向键 / 鼠标 / 点击屏幕）
- 收集金币 **+1**，碰到炸弹 **-1 条生命**（共 3 条生命）
- 集满 **100 枚金币**即获胜

## 🛠️ 技术说明

- 单文件 HTML：`index.html`（Three.js 已内嵌，双击即可离线运行）
- 所有可调参数集中在文件顶部，代码按模块添加中文注释

## 📦 本地运行

直接用浏览器打开 `index.html` 即可，或访问在线版本。
