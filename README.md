# 小熊快跑 · 四季滚动天空 3D

用 **Three.js** 制作的 3D 网页跑酷小游戏：操控一只小熊在悬空跑道上奔驰，
场景会随**春夏秋冬**缓慢轮换。

## 🎮 在线试玩

**https://fyxhh.github.io/rolling-sky-game/**

手机或电脑浏览器打开即玩（iPhone 用 Safari 打开后：分享 → 添加到主屏幕，就是个 App）。

## 🕹️ 操作

| 操作 | 键盘 | 手机 |
|---|---|---|
| 左右移动 | `←` `→` / `A` `D` | 滑动或点击屏幕 |
| 跳跃（可二段跳） | `空格`（长按跳更高） | 双指点击 / 上滑 |
| ⚡ 闪电加速 | `F` / `Shift` | 点击左下角 ⚡ 按钮 |

## 🌸 四季系统

每收集 **100 枚金币** 推进一个季节，且渐变速度被限制在每秒 2%，所以是**慢慢变**而不是瞬间切换：

| 季节 | 视觉 | 特色 |
|---|---|---|
| 🌸 春 | 浅绿柔亮 | 路边花草、少量花瓣飘落 |
| 🌿 夏 | 高饱和翠绿 + 斑驳树影 | 水塘障碍、浮尘飘动 |
| 🍁 秋 | 暖黄橘红 | 地面落叶、跑动卷起枯叶 |
| ❄️ 冬 | 冷调淡青白 | 薄雪、结冰路面（打滑 + 提示音）、稀疏雪花 |

切换时**天空 / 雾 / 灯光 / 地砖 / 障碍 / 飘落物 / BGM** 全部同步插值。

## ⚡ 闪电加速

每满 **10 分**获得一次加速（最多存 3 次），释放后 **5 秒**内：
速度 ×1.5、视野拉宽、头顶出现旋转的 3D 闪电模型，并**可直接撞碎障碍**。

## 🎵 音乐

WebAudio 实时合成（无需音频文件），四季各有性格：

- 春：轻快电子 + 木笛点缀，中速
- 夏：鼓点清晰、节奏加快、偏活力电子
- 秋：节拍放缓、柔和合成器、鼓点弱化
- 冬：空灵简约、鼓点变少、冷感音色

四季都保留稳定鼓点作节奏参考；换季时 BPM / 音色 / 音量平滑过渡；
**BGM 音量低于脚步、碰撞、金币等音效**，保证操作反馈听得清。

## 🛠️ 技术

- `index.html`（three.js 已内联）+ `bear.glb`（小熊模型）
- 模型由 75MB 高模（84 万顶点 / 150 万面 / 3 张 4K 贴图）精简而来：
  **3 万面 + 1024 贴图 → 1.2MB**
- 可调参数集中在游戏代码顶部 `CFG` 中，方便调手感
- 源码分模块放在 `_src/`；改完 `game.js` 后运行 `python _src/build.py` 重新生成页面
